What's on the bar

Nine things you check fifty times a day.

Every shot below is DevBar running on Windows 11 - real ports, real containers, real sessions. Each module is event-driven or polls only while its card is on screen, so none of it costs you anything when the bar is closed.

The Jarvis tab

Press a key. Talk. It does the thing.

Not a chatbot in a window - a voice loop wired into the modules above. It hears you with streaming speech recognition, thinks on free-tier models, calls real tools on your machine, and speaks the result while the rest of the answer is still being generated.

01

You press

A global shortcut you can rebind. The mic is shut until that moment - or until you say "Hey Jarvis", if you turn the on-device wake word on.

0 ms idle cost
02

It hears

Streaming transcription, with pauses handled so you don't get cut off mid-thought.

~500 ms after you stop
03

It thinks

Your words, your pinned profile and the tool list go to the first model in your chain; the next one takes over on a rate limit.

~400 ms to first word

27 tools: ports, containers, repos, clipboard, apps, screen, mail, calendar, shell. Destructive ones are read back and wait for your yes.

What you can say

It knows your machine, and a bit about you.

  • "What's on port 3000? Kill it." Reads the real TCP table, then asks before killing.
  • "What does this error say?" Looks at your active window and quotes the line and file.
  • "Type this into the editor…" Dictation straight into whatever has focus.
  • "What's on today?" Google Calendar and Gmail, once you connect them.
  • "Remind me in twenty minutes to push." Survives a restart, and it speaks up when it's due.
  • "Remember that…" Keeps lasting facts in a local database you can read and delete.

Bring your own keys

Built to run on free tiers.

DevBar has no server and resells nothing. You paste your own keys, and they're encrypted on your machine with Windows DPAPI. Every layer has a free option, and the voice can run entirely offline.

GroqThe brain. gpt-oss-120b, then 20b as backup.free tier
Google GeminiFallback brain, vision for your screen, and web search.free tier
Piper · on-deviceThe voice, running locally at ~20× real time.free forever
DeepgramStreaming speech recognition, and the Aura-2 voice.usage-based
OpenAI · Anthropic · Cerebras · OpenRouter · OllamaDrop any of them into the model chain and reorder it in settings.optional

Your data

Local by default. Honest about the rest.

A voice assistant that can read your mail should be exact about what leaves your computer. So here it is, without the marketing fog.

Privacy policy Terms of service
Never leaves your PC local
  • API keys and Google tokens - DPAPI-encrypted, readable only by your Windows account
  • Memory and reminders - one SQLite file you can open, edit or delete
  • Wake-word listening - an on-device model; nothing is sent until it hears you
  • Your mail and calendar - fetched to answer, never stored or indexed
  • Usage - there's no telemetry to send, and no server to send it to
Sent only while you're talking your keys
  • Your voice → speech-to-text, for the length of the conversation
  • Your words + pinned profile + tool results → the model you chose
  • A screenshot → the vision model, only when you ask about the screen
  • The reply text → the cloud voice, unless you pick a local one

Open source

A module takes an afternoon.

DevBar is MIT licensed and built to be extended. A module is five methods; drop the compiled DLL into %LOCALAPPDATA%\DevBar\modules\ and it appears as a tab. The only hard rule is the performance contract: do nothing between OnCollapsed and the next OnExpanded.

IDevBarModule.cs
public interface IDevBarModule
{
    // Stable id, used in config.
    string Id { get; }
    string DisplayName { get; }
    string IconGlyph { get; }

    // Built once, lazily, on first view.
    UserControl BuildCard();

    // Paged in: start timers, fetch data.
    void OnExpanded();

    // Paged out: stop everything. Go quiet.
    void OnCollapsed();
}

Install

On your screen in about a minute.

No admin rights, no installer prompts you have to think about. Jarvis is optional - the bar works without a single API key.

Step 1

Get the build

Grab the latest Windows installer from GitHub Releases, or build it yourself with the .NET 8 SDK.

git clone https://github.com/Vivek-C-Shah/DevBar
cd DevBar
dotnet run --project src/DevBar

Step 2

Hover the top edge

The pill sits centred at the top of your primary screen. Hover it, page through the tabs, pin it if you're waiting on something.

%LOCALAPPDATA%\DevBar\config.json

Step 3 · optional

Wake Jarvis up

Open the Jarvis tab, click the gear, paste a Deepgram key and a free Groq key. Then press the shortcut and talk.

Ctrl + Alt + Space
